# `vue-style-guide` Claude Skill

Enforces the official Vue.js style guide rules as defined by the Vue core team at [vuejs.org](https://v2.vuejs.org/v2/style-guide/), organized by priority so teams know what's essential and what's a matter of consistency.

## Installation

Launch Claude Code first:

```bash
claude
```

Then from within Claude Code, add the marketplace and install the skill:

```bash
/plugin marketplace add eduardosch/ai-instructions

/plugin install vue-style-guide@eduardosch-marketplace
```

## Uninstalling

```bash
/plugin uninstall vue-style-guide

/plugin marketplace remove eduardosch-marketplace
```

## Usage

```
/vue-style-guide
```
